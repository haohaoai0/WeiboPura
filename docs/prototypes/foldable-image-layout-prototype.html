现网真实问题归因 (为什么截图排版错了？)

  • 1. 高度死板锁死在 106vp：代码中 pictureCellHeight 对 3 图直接返回固定 106vp。折叠展开大屏上单列宽达 240vp，导致单元格变成 2.3:1 的极端扁平窄条。
  • 2. 竖图/长截图被居中腰斩：评论截图是典型的 9:16 甚至 9:21 超长图，因 objectFit(Cover) 居中裁切，头部的核心观点和底部的精彩回复全部丢失，只露出中间无意义碎片。
  • 3. 横屏无限拉伸无边界：大屏横屏（1100vp）若不做分栏或宽度限制，3张图片直接拉扯到 1000vp 宽度，视觉松散且阅读极度吃力。

方案 A 核心破局点 (推荐落地方案)

  • 1. 3:4 黄金画幅 + 顶部锚定：长竖图按 3:4 自适应高度（220~270vp），并采用 top center 锚定，第一屏即可完整阅读长截图的标题与第一条热评！
  • 2. 优雅最大内容宽 (Max-Width 620vp)：大屏竖屏下居左/居中规整排列，无论手机还是折叠屏，网格密度均保持最佳视线聚焦。
  • 3. 大屏横屏左右双栏分栏 (Split View)：横屏直接切换为鸿蒙规范推荐的左右分栏：左边大图文，右边刷评论，彻底消灭上下大幅度滚动的疲劳！

备选方案对比

  • 方案 B (画报拼图)：1大主图（左占60%）+ 2小副图（右占40%垂直均分）。视觉冲击力强，极具杂志排版感，但右侧2张副图依然会被压缩。
  • 方案 C (画卷胶卷)：横向滑动单卡（3:4比例）。适合连续多张长截图翻阅，但无法一屏同时对比3张内容。
