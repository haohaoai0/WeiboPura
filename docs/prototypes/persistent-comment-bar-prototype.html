方案 1：极致灵动社交坞 推荐

左侧大胶囊输入 + 右侧主贴三大互动（赞 / 藏 / 享）。
符合主流大厂顶级体验，打字与点赞互不冲突，常驻栏只服务于主贴互动，轻触直接呼起输入面板。

方案 2：纯粹专注创作坞

长胶囊输入 + 配图 + 表情 + 独立发送胶囊。
聚焦评论创作本身，不承载主贴点赞。输入框始终明确提示“写评论…”，右侧直接提供图片与表情快捷入口。

方案 3：一体流光微胶囊

微头像 + 居中长胶囊 + 尾部微圆发送纽。
一体成型的连续悬浮跑道圆胶囊，带有薄荷绿主题细轮廓与柔光阴影，形态紧凑、极致原生感。
