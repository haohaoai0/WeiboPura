## 行为与边界

- 新详情页默认 `WeiboCommentSort.Hot`；正文页内切换排序不会混用缓存、分页游标或迟到的请求结果。
- 根评论改为 `weibo.com/ajax/statuses/buildComments`；`flow=0` 热度、`flow=1` 实时。分页继续使用同一排序和服务端 `max_id`。真实账号/匿名态可用性仍需接口实测。
- 首屏缓存纳入排序；发送或点赞成功后的失效会分离尚未结束的旧预取，不能将旧结果重新写回缓存。
- 16 位以上的数值评论 ID 与游标在 `JSON.parse` 之前转成字符串，适用于根评论和楼中楼。
- 服务端游标仍在前进的重复页不等于末页。连续三页无新 ID 时暂停自动请求，保留手动“加载更多”；获得新 ID 后恢复自动加载。
- 隐藏仅使用位移、透明度、触摸与无障碍屏蔽，不增减滚动视口高度。评论区尚未进入视口时不隐藏；编辑、选图、发送及表情选择期间保留输入交互。
- 回复使用原生底部 Sheet 和系统键盘，不绘制仿九宫格键盘。键盘避让为 `TRANSLATE_AND_RESIZE`；灰色输入区显示 `回复 @用户名`。快捷表情与完整表情选择都插入到实际选区。
- 点击背景/返回/更多菜单可收起面板，草稿和配图保留。“更多”可取消回复、转为评论当前微博；选图及发送期间不能改变回复目标。
- 只有 `publishComment` 成功后才关闭面板、清空草稿，并重新加载当前排序。失败保留内容与已上传图片，避免重试重复上传。
- 排序期间点赞回执按 ID 更新当前根评论/楼中楼，不更新脱离列表的旧对象。请求开始前的读取版本用于防止迟到读覆盖成功写；成功写之后启动的新读取仍以服务器为准。
- 收起楼中楼会递增线程请求代次；旧回执不能重新展开，也不能清除同 ID 新展开请求的加载标志。
