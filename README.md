# Fluo

**鸿蒙原生微博客户端**

[功能介绍](#功能介绍) · [使用说明](#使用说明) · [问题反馈](https://github.com/HaiYangMa13/fluo/issues) · [隐私政策](docs/PRIVACY.md)

</div>

Fluo 是一个第三方微博客户端，用 ArkTS / ArkUI 编写，面向 HarmonyOS。

刷关注、看热搜、读长文、翻评论，是它最常用的几个场景。界面默认采用鼠尾草绿配色，支持深浅色模式，保留微博的常用功能，不照搬官方客户端的页面。

## 功能介绍

### 微博与搜索

- 浏览关注和推荐信息流，左右滑动切换。
- 在「发现」查看热搜，输入关键词时查看用户、话题和搜索建议。
- 按综合、实时、用户、视频、图片筛选搜索结果。
- 查看用户主页、自己的微博、收藏和点赞记录。

### 正文与讨论

- 展开长微博，查看图片和视频；视频支持进度调节、倍速与全屏播放。
- 在详情页切换转发、评论和赞列表，查看楼中楼回复，按热度或时间排列评论。
- 打开正文中的话题、用户提及和网页链接。
- 通过浏览历史找回看过的微博，不必为了留个记录而先点收藏。

### 发布与分享

- 发布文字和图片，评论、回复、转发，以及点赞、收藏和关注。
- 保存未发出的草稿，区分发微博、转发、评论和回复的编辑内容。
- 调用系统分享，或将微博生成图片卡片；分享卡片可切换明暗样式。
- 查看收到的消息，从消息进入相关微博和讨论。

## 界面和阅读

Fluo 的主要页面是原生界面，不是把微博网页套进一个壳里。登录和外部网页使用内嵌浏览器。

导航栏和评论栏采用鸿蒙原生悬浮材质。主题颜色、深浅色模式和字体大小可以调整，图文布局会根据窗口宽度变化，兼顾手机小屏和折叠屏展开后的阅读。

阅读位置、搜索历史和草稿会保存在本机。点进详情再返回、切换搜索分类时，会保留已有的浏览状态，减少反复找回刚才内容的操作。

折叠屏布局、手势和页面切换仍在调整中。如果某个地方不好用，欢迎直接提出来。

## 使用说明

在「我的」打开微博登录页，完成登录后即可使用关注流和账号相关功能。部分公开内容可以尝试以访客身份浏览，但微博也可能要求登录或验证。

Fluo 依赖微博提供的接口，**不能保证与官方客户端拥有完全相同的功能或可用性**。登录失效、访问限制、接口变化都可能影响使用；遇到验证码或账号验证，请按微博页面的提示处理。

点赞、评论、关注、转发和发布都由你主动操作，Fluo 不提供自动点赞、定时发布或批量互动。登录凭据保存在本机，用于访问微博服务，不会上传到本项目的服务器。具体说明见 [隐私政策](docs/PRIVACY.md)。

## 反馈问题

请在 [Issues](https://github.com/HaiYangMa13/fluo/issues) 留下问题或建议。报告故障时，最好附上：

- 设备型号和 HarmonyOS 版本；折叠屏请说明当时的折叠状态与屏幕方向。
- 从哪个页面开始、做了哪些操作、实际出现了什么结果。
- 能说明问题的截图或录屏，以及可公开访问的微博链接。

请遮住私人内容，不要提交 Cookie、登录凭据或验证码。
